# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Use GitHub's private reporting: open the **Security** tab of this repository and select **Report a vulnerability**. Include the steps to reproduce and the version (commit) you tested.

You get an answer within 7 days.

## Scope

Rivell has no sign-in yet. It runs with one fixed local identity and is meant to run on your own machine. Do not expose it to the internet. Reports that only say "there is no authentication" are known and out of scope.
